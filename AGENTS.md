# Работа над bible-app

## Обязательное обновление локального стенда

Пользователь первым шагом проверяет каждую доработку на http://localhost:3000/.
После изменений приложения сразу обновляйте этот стенд, до сообщения о готовности:

1. Выполните необходимые проверки изменений.
2. Пересоберите и перезапустите локальный сервис: `docker compose up -d --build app`.
3. Проверьте, что http://localhost:3000/ доступен и отдаёт новую сборку; для изменений
   API проверьте также соответствующий маршрут.

Изменения исходников и `npm run build` сами по себе не обновляют работающий Docker-контейнер.
Отдельный предпросмотр на другом порту не заменяет обновление стенда на порту 3000.
Сохраняйте существующий том `bible-data` и пользовательские данные; не используйте
`docker compose down -v` для обычного обновления.
Обновление локального стенда входит в задачу и не требует отдельного запроса пользователя.
Для изменений только документации пересборка не нужна.
Если обновление или проверка заблокированы, явно сообщите об этом, не называя стенд обновлённым.

Пуш и production-релиз выполняйте по запросу пользователя после локальной проверки.
